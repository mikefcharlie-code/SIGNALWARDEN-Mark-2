# God's Eye View capability coverage

**Review basis:** upstream `gods-eye-view` at [`7be5937`](https://github.com/bilawalsidhu/gods-eye-view/tree/7be5937fc3e3b10cdfa8d3f833536167268768ad), the checked-out SignalWarden PR18 source, README, and the current WorldView UI. This is an integration inventory, not a claim that SignalWarden imported the upstream application or its assets.

## Status vocabulary

- **Implemented:** the behavior is present in this checkout and bounded by local code/tests. “Implemented” does not mean upstream parity or production live coverage.
- **Partial:** a local primitive or UI exists, but a live source, full operator workflow, provider terms, or upstream-equivalent behavior is absent.
- **Manual/imported:** the UI accepts a user-authorized, validated local pack; no provider adapter or authenticity claim is implied.
- **Deferred/unavailable:** no current SignalWarden implementation; do not describe it as available.

## Reconciled capability inventory

| Capability | What the upstream repository documents/contains | Current PR18 status and safe interpretation |
|---|---|---|
| Native globe / scene | Cesium globe, terrain/imagery, picking, labels, trails, scene/layer lifecycle, and a photorealistic Google 3D Tiles path | **Partial, implemented schematic shell.** Three.js renders an original perspective 3D globe with coarse original outlines, graticule, markers, drag rotation and a 2D fallback. Optional opt-in imagery/terrain tiles remain coarse and bounded; there is no Cesium, Google Photorealistic 3D Tiles, or navigation-map accuracy. |
| Global context / geographic focus | Global place/entity search, geo URI search, city presets and camera handoff | **Implemented bounded UI.** Local city presets, decimal coordinates and `geo:` search move the schematic globe. Global context saves/restores the local view and enables all context layers. It is not a global geocoder or upstream camera service. |
| Detection HUD | Detection/overlay presentation and operator HUD controls | **Implemented as presentation state.** The detection toggle changes contact emphasis/labels; it is not a sensor detector, classifier, alert engine or proof of detection. |
| Search, nearby tracking and analyst context | Search/entity focus, contact proximity and analyst-oriented views | **Implemented bounded local queries.** Text filtering, distance ordering around the current center, layer counts, `count`, `filter` and confidence/time `rank` commands operate on records already in memory. The roster has 250 km / 1,000 km / global scope and a selected-contact view-follow toggle; neither is an identity tracker or global search index. |
| Live aircraft | OpenSky-derived flights, local ADS-B, military awareness/classification and a larger contact roster | **Partial.** The current UI can manually opt in to the bounded `adsb.lol` point adapter (HTTPS GET, radius ≤100 nautical miles, 60-second throttle, coarse observations, no identity enrichment). It is not OpenSky parity, global coverage, military classification or a cockpit view. |
| Ships / AIS | Live AIS layer, selection, trails and metadata | **Partial: bounded opt-in relay.** The `vessels` layer can show self-reported AIS positions through the disabled-by-default server relay, with provider/configuration and stale labels, bounded boxes, latest-per-MMSI memory retention, and no trails, global coverage, owner/crew enrichment, or transmit path. Synthetic markers and authorized packs remain separate. |
| Satellites / orbital elements | Satellite catalog and tracked objects | **Partial.** Users may paste a checksum-validated TLE for local SGP4 geometric pass calculations. The same TLE supplies a current propagated position marker; there is no bundled/live catalog fetch, continuous global track or visibility/weather assessment. |
| Earthquakes | Seismograph/event layer | **Implemented bounded live adapter.** `refreshUsgsEarthquakes` performs an explicit network-opt-in, bounded USGS GeoJSON request (trailing 24 hours, up to 100 records, at least 60 seconds between refreshes) with source labels. It is not a historical archive or seismic early-warning service. |
| Traffic | Real-road geometry with simulated vehicle motion from aggregate traffic data, explicitly not precise live vehicle tracking | **Partial: bounded public context.** Disabled-by-default relays can list authority camera metadata and fetch one selected snapshot, plus provider traffic context where configured. No plate reading, face recognition, image analysis, precise vehicle tracking, or mission use exists; synthetic/imported traffic remains distinct. |
| Public CCTV / camera locations | Public-camera catalog, camera models, heights, snapshots, poses and provenance | **Partial: opt-in public catalogs.** Authority catalogs and a selected-camera snapshot path are bounded, source-labelled, and never image-analyzed or cached as a live stream. Published poses are not verified detections; imported packs remain available. |
| ALPR locations | OSM-derived ALPR/location context in the upstream scene | **Manual/imported only.** A clearly synthetic “ALPR location (no plates or imagery)” marker and `alpr` layer exist. No plate capture, recognition, lookup, imagery or live ALPR provider is implemented. |
| Street-level imagery | Mapillary, Google Street View, KartaView and Panoramax coverage/viewers with provider credits and terms | **Partial metadata search.** The opt-in mobility relay can return bounded metadata and provider links for supported sources; thumbnails load only on user action, the server does not download imagery, and there is no panorama viewer, coverage layer, or Google Street View. |
| Radio / SDR | Radio layer and receive-oriented SDR/signal notices | **Partial directory metadata only.** The mobility surface can list station-submitted context while dropping stream URLs; there is no browser SDR capture, signal data, playback, recording, or operator control. |
| Transit / GBFS | Transit and bikeshare feeds/vehicles from agency and GBFS feeds | **Partial bounded relay.** Configured GBFS and GTFS-realtime vehicle-position feeds can be read through the disabled-by-default relay with area, freshness, and polling limits. A feed convention is not a license; no static schedules, trip updates, alerts, route shapes, plate decoding, or control path is implemented. |
| Directions / routing | Route geometry, directions layer and scene/camera integration | **Unavailable/deferred.** No routing provider, key handling or route renderer exists. |
| GNSS | Receiver/position observations separate from aircraft feeds | **Partial.** Read-only telemetry contracts/documentation and imported observations can expose GNSS fields; WorldView does not command navigation or write back to an autopilot. |
| GNSS interference context | Daily GPSJAM aggregate of aircraft-reported low navigation-accuracy shares in H3 cells | **Implemented, separate opt-in display layer.** A disabled-by-default relay and second, feature-specific checkbox retrieve bounded UTC-day aggregates; cells are inferred context, not jammer detections/locations, real-time observations, navigation inputs or commands. GPSJAM cells do not enter aircraft records, analyst/Warden context, tracking, flight-control paths or ground-vehicle odometry. See [GPSJAM limits and terms](worldview-gpsjam.md). |
| Weather | NOAA GFS, ECMWF, nowCOAST, lightning and cyclone products | **Partial, forecast/context only.** `refreshNoaaWeather` provides opt-in NOAA/NWS point forecasts; the current weather/wind surfaces add bounded model forecast context and air-quality labels through separate disabled-by-default relays. Forecasts are not observations; direct GRIB, native nowCOAST, lightning, and complete cyclone layers remain unavailable. |
| Ocean / maritime environment | Bathymetry, nautical charts, sea surface temperature and other ocean context around AIS/vessel views | **Partial opt-in context, not navigation.** The ocean surface supports bounded bathymetry/chart/SST-style overlays, marine model context, and selected buoy/tide reads where configured. Nothing is an official chart, tide table, navigation solution, or vessel-control input. |
| Fires / perimeters | NASA FIRMS, incident feeds and perimeters | **Partial bounded hazard context.** Disabled-by-default hazard relays can expose provider-reported thermal anomalies, perimeters, event metadata, and cyclone context when terms/configuration permit. These are reports/anomalies, not confirmed incidents; no wildfire assets are bundled. |
| Imagery / basemaps | Google/Cesium credit, recent imagery, Google Photorealistic 3D Tiles, Natural Earth and OSM-derived assets | **Partial opt-in tile layers.** The schematic globe remains the offline default. Bounded keyless and server-relayed imagery/terrain layers include visible attribution and provider status; there is no Cesium, Photorealistic 3D Tiles renderer, offline tile bundle, or navigation-grade accuracy. |
| Scene styles | Day/night/FLIR-like presentation, clean/recording modes, labels, trails and overlays | **Implemented cosmetic styles only.** Standard, CRT, NVG, FLIR, Noir and Snow are UI presentation states. They do not produce sensor-derived night vision/thermal data and do not provide upstream recording/clean-view attribution behavior. |
| Local-first AI analyst | Natural-language context analysis, grounded reports and safe UI intents | **Implemented bounded analyst.** Typed tools query preloaded region/time/layer and platform evidence, compare records and loaded history, explain freshness/conflicts/gaps, cite record/source/time and draft separate advisory briefings/notes. Deterministic fallback needs no model or WebGL. Configured local Qwen can only organize fixed cited findings; external AI requires explicit browser and server consent. No arbitrary tools, identity enrichment, target ranking or aircraft/weapon instructions. See [analyst configuration and limits](worldview-ai-analyst.md). |
| Voice | Upstream realtime agent and voice verbs for annotations, camera and search | **Partial, browser speech input only.** Separate opt-in discloses browser audio egress. Scene analyst stages transcripts and queries, allows bounded layer/camera UI navigation and drafts annotations for review, and filters unsafe instructions. The legacy speech entrypoint uses the same filter and cannot bypass draft/query review. No realtime agent, audio synthesis, server transcription or actuation. |
| Replay / time | Track trails, timelines, saved director shots and a warning that historical world replay is expensive/unfinished | **Implemented bounded local replay.** The UI has play/pause and a time scrubber over a two-sample original synthetic scenario (never generated from fetched provider contacts); `replayAt` interpolates compatible samples. This is not historical world replay, source snapshot retention or cross-provider reconstruction. |
| Annotations | Whiteboard/annotations associated with scene operation | **Implemented local annotations.** `annotate` creates bounded point/text annotations and scene export preserves them. They are operator notes, not evidence or provider observations. |
| Director shots / keyframes | Saved director shots and camera choreography | **Implemented bounded keyframes.** The UI captures local center/zoom keyframes and interpolates smoothly between up to eight captured keyframes, with shortest-longitude interpolation and pause/scrub controls. It is not a cinematic recording system. |
| Share scenes | Shareable scene state | **Implemented validated URL sharing.** Scene state is schema-validated, credential-filtered and copied as a URL when clipboard access is available. A shared URL contains state, not data-provider credentials or a server-persisted scene. |
| Import/export | Scene/data-pack workflows | **Implemented bounded local import/export.** Validated JSON scenes and observation packs are downloadable/uploadable with size and schema limits. Importing an authorized pack does not verify provenance or turn it into a live source. |
| 3D models | Bundled aircraft/scene models with per-asset attribution | **Partial, original generic 3D presentation.** Current markers are generic procedural Three.js primitives (cone/box/octahedron). No authentic per-airframe model, upstream GLB, terrain or sky asset is bundled. |
| Launches / space events | Launch Library 2 launch/event data | **Partial bounded context.** The disabled-by-default space relay can expose selected launch/event metadata and past observation context when configured; it does not establish a sighting, orbit, or operational schedule. |
| Air quality | Upstream/third-party environmental context where documented | **Partial point context.** Modelled and measured values are labelled separately, source-linked, and bounded; no gridded air-quality layer, health advice, or certified-monitoring claim is made. |
| Cables, datacenters and dams | TeleGeography submarine cables plus OSM/OpenInfraMap datacenter and dam snapshots | **Partial live OSM context, no bundled assets.** A bounded, attributed infrastructure query may show datacenter/dam context when the mobility relay is enabled. TeleGeography cables and upstream snapshots remain explicitly excluded. |
| Local extension model | Separation of layers, source slots, catalogs, tools and scene services | **Implemented as an architectural boundary.** PR18 has typed observations, provider metadata, validation, import/export and read-only adapters; it has not imported the upstream runtime/catalog. |

## Source boundary

The implemented source slice includes **USGS earthquakes, NOAA/NWS `weather.gov` forecasts, `adsb.lol` aircraft points, and the separately gated World View context relays** described above. Every external read remains manually/session opted-in, bounded, and source/freshness labelled. Synthetic demo records and user-authorized observation packs remain separate from provider reads. Restricted upstream cable/flood datasets and unreviewed assets remain excluded.

**API credentials:** Provider credentials, where a current relay supports them, are read server-side only and are never exposed in client bundles, scene URLs, logs, or response bodies. A missing key is `not_configured`; a provider row or upstream requirement is not evidence that a secret exists. Keyless/public endpoints remain subject to their current terms and quotas.

**Safety boundary:** every marker is an observation or presentation object. WorldView remains read-only: it must not send flight commands, change an autopilot mode, alter a mission, bypass signing/freshness/replay/RBAC, or add Lattice deployment behavior.

## Provenance notes

Upstream qualifiers survive integration: feeds may be live or refreshed, traffic may be simulated on real roads, camera poses may be coarse estimates, and a pin/line/cone/model-rendered object is not proof of an event or location. Future implementations must be original SignalWarden code, preserve provider notices, and receive a separate license/provenance review.
