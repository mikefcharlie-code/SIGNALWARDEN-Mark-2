# Warden-TH dependency and license review

The local inference runtime is pinned to NumPy 2.2.6 and ONNX Runtime 1.31.1. The training-only environment is pinned to NumPy 2.2.6 and ONNX 1.23.2; ONNX export dependencies are kept out of the inference environment. The [official ONNX Runtime installation guide](https://onnxruntime.ai/docs/install/) documents the CPU Python package, and [PyPI’s ONNX Runtime metadata](https://pypi.org/project/onnxruntime/) records the release and supported Python versions. Exact-version package metadata is available for [NumPy 2.2.6](https://pypi.org/project/numpy/2.2.6/) and [ONNX 1.23.2](https://pypi.org/project/onnx/1.23.2/).

The isolated runtime’s installed dependency licenses were reviewed: ONNX Runtime (MIT), NumPy (BSD), FlatBuffers (Apache-2.0), Packaging (Apache-2.0 OR BSD-2-Clause), and Protocol Buffers (BSD-3-Clause). The training environment adds ONNX (Apache-2.0), ml_dtypes (Apache-2.0), and typing_extensions (PSF-2.0), alongside NumPy and Protocol Buffers. These runtime and training package trees returned **no known vulnerabilities** in `pip-audit`. The management frontend also returned **no known production dependency vulnerabilities** in `pnpm audit --prod`; its existing package-notice check verified 16 packages.

The generated model itself is project-produced from seeded synthetic telemetry only; no third-party dataset or pretrained weight is included. The repository has not selected an open-source license, so the generated artifact is marked `NOASSERTION`; that is not a grant of permission for third-party use. Both generated artifact hashes are recorded in `configs/warden-th-artifact.json` and the local-only entry in `configs/local-ai-models.json`. Weights remain outside Git and have no automatic download route.
