NATIVE COMPONENTS USED BY THE OFFICIAL KISS-ICP WHEEL

KISS-ICP v1.3.0's CMake dependency scripts pin the following source versions.
The official Linux CPython 3.12 wheel inspected for this integration has no
separate Eigen, Sophus, oneTBB, or robin-map shared-library dependency (its
native extension links only to platform system libraries); these components are
therefore treated as native code within the KISS-ICP wheel, not as additional
runtime Python packages. Versions and license texts are cited to upstream:

- Eigen 3.4.0 — primarily MPL-2.0. Eigen notes that some individual files
  have separate third-party BSD/LGPL licenses; see both its COPYING.README and
  COPYING.MPL2: https://gitlab.com/libeigen/eigen/-/tree/3.4.0
- Sophus 1.24.6 — MIT; its LICENSE notice reads "2012-2017 Steven Lovegrove":
  https://github.com/strasdat/Sophus/blob/1.24.6/LICENSE.txt
- oneTBB 2022.1.0 — Apache-2.0: https://github.com/uxlfoundation/oneTBB/blob/v2022.1.0/LICENSE.txt
- tsl-robin-map 1.4.0 — MIT; copyright (c) 2017 Thibaut
  Goetghebuer-Planchon: https://github.com/Tessil/robin-map/blob/v1.4.0/LICENSE

The upstream Python pyproject declares the build backend scikit-build-core and
pybind11 without version pins. They are build-time requirements, not packages
in this runtime lock; wheel-only installation avoids invoking the build
backend. The pybind11 headers are BSD-3-Clause (copyright notice in
https://github.com/pybind/pybind11/blob/master/LICENSE). The build backend's
license is Apache-2.0 (https://github.com/scikit-build/scikit-build-core).

No source captures, sample datasets, pretrained model files, or learned weights
are redistributed by this feature. Synthetic scans in tests are generated at
runtime in temporary directories.
