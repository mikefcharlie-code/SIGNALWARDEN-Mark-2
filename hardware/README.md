# Hardware workstream

Start with `inventory-template.csv` and reviewed requirements, then add interfaces, revision records, source design files, and supplier references. The CSV is an empty template, not a bill of materials or procurement recommendation.

Track airframe, propulsion, power, flight controller, sensors, communications, and ground equipment as applicable after scope review. Record compatibility, power/interface budgets, mass, and test evidence for actual selected parts. No physical design has been validated.
